# Learning Notes · Flutter

移动端面向 iOS / Android，使用 Riverpod、HTTP 和二进制 WebSocket / Protobuf。

先启动 Nest API，再在此目录运行 `flutter pub get`、`flutter run`。
完整启动说明、设备地址和协议生成见根目录 [README](../../README.md)。

本机 SDK 为 `../../.tools/flutter/bin/flutter`，默认 API 为 `http://127.0.0.1:4000`。
Android 模拟器使用 `--dart-define=API_URL=http://10.0.2.2:4000`。
