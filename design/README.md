# 个人英语学习记录 App · 双端交互设计 v0.3

状态：基础流程采用 v0.1 方案，v0.2 增加微信风格配色、深色模式与设置导航，v0.3 增加中文和英文界面。此目录为产品设计资料，不是正式业务实现。

## 已确认的需求

- 产品服务个人英语学习与雅思备考，先满足本人使用，保留后续扩展空间。
- 首页参考微信的会话组织方式，支持新建会话。
- 每个会话是个人学习记录空间；自己发送内容、回看，暂时没有对方回复。
- 聊天详情支持文字、语音、图片三类消息。
- 手机与桌面一起设计，共用业务流程，分别适配布局。
- 配色参考微信，支持浅色与深色模式。
- 手机新增设置 Tab；桌面左侧导航栏底部提供设置按钮。
- 支持简体中文与 English，可从两端设置入口切换界面语言。

## 当前设计方案

- 首页显示会话名称、最近消息摘要和最近更新时间，并支持按名称搜索。
- 新建会话时可填写名称，不填写时使用“新会话”。
- 手机：列表与详情分成两个页面；桌面：左侧会话列表，右侧详情。
- 所有消息靠右展示，通过日期分隔；详情中用“个人记录”解释会话用途。
- 语音采用点击开始、点击结束的录制方式，结束后试听，可重录或发送。方便两端保持一致。
- 图片先选取、预览确认，再发送；消息内点击放大。
- 附加内容与文字分别发送；第一版每条图片消息包含一张图片。
- 本轮不展示社交未读计数、联系人、群聊和已读状态。
- 手机一级导航为“会话 / 设置”；进入聊天详情时隐藏 Tab，返回后恢复。
- 手机设置页提供外观选项；桌面点击左下角齿轮弹出设置面板。
- 外观支持“跟随系统 / 浅色 / 深色”，默认跟随系统；切换即时生效，并在当前浏览器保存。正式客户端按设备保存，不将外观作为云端学习数据同步。
- 微信风格基色：品牌绿 `#07C160`，浅色气泡 `#95EC69`，深色气泡 `#2ACB82`；背景、分隔、输入区、弹窗与设置同步适配主题。
- 设置上方新增“语言”入口，手机进入语言子页面，桌面进入语言设置面板。选项始终用语言自身名称显示为“简体中文 / English”。
- 默认中文；语言选择立即生效，在当前设备保存，重新打开后恢复。语言与外观偏好相互独立。
- 翻译范围包含界面导航、按钮、占位提示、空状态、录音面板、弹窗、消息类型摘要与可访问名称。用户的会话名称、笔记、消息、图片内容和文件名保留原文。
- 切换语言保留当前会话、搜索条件与未发送文字。两端演示共用当前浏览器的语言选择，正式客户端各自保存设备偏好。

## 页面与流程

1. 首页：搜索、会话列表、新建入口；新会话创建后进入详情。
2. 会话详情：标题、个人记录提示、消息时间线、文字输入、图片与语音入口。
3. 新建会话弹窗：名称输入、取消、创建。
4. 图片预览：发送前确认、消息图片查看。
5. 录音面板：录制计时 → 试听 → 发送或重录。
6. 手机设置 Tab：外观选项与当前选中状态。
7. 桌面设置面板：从左下角齿轮进入，关闭后继续当前会话。
8. 语言设置：设置 → 语言 → 简体中文 / English，选择即生效，可返回设置。

原型内的“手机/桌面”切换属于评审工具，不属于 App 功能。

`overview.png` 与 `overview-dark.png` 分别为 v0.2 浅色和深色布局总览，对应 `.svg` 为可缩放源文件；总览图是独立绘制的页面示意，不是交互原型截图。v0.3 新增的语言设置以交互原型为准。

## 原型使用与边界

打开 `wireframes.html`，或在项目根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:4173/design/wireframes.html`。

- 可点击：会话切换、新建、搜索、文字发送、图片选取/预览、模拟录音/试听、手机返回、设置 Tab、桌面设置、三种外观选项与两种界面语言。
- 两端展示同一份浏览器内示例数据，便于比较适配。
- 录音与播放为模拟，不申请麦克风权限，不录制真实音频。
- 图片仅在当前浏览器内预览，不上传；学习记录刷新后重置，外观与语言偏好保留。
- 顶部外观预览按钮是评审工具；正式 App 从各端设置入口调整外观。

## 后续正式设计需要覆盖的状态

- 麦克风权限拒绝、设备不可用、录制中断。
- 发送中、失败重试、断网、历史加载与空列表。
- 切换会话或离开时，未发送文字、图片与录音的处理。
- 音频格式、时长与图片体积限制，以及消息删除/会话重命名需求。

正式功能的验收至少包含：保存成功后重新打开仍能查看消息和回放录音；跨端查看一致；失败重试不重复创建记录。
